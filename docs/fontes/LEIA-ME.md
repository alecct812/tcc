## Como conferir

O Wayback Machine entrega os bytes originais de uma captura quando se acrescenta `id_` depois do
carimbo de data, por exemplo
`https://web.archive.org/web/20260923175048id_/https://support.claude.com/en/articles/14604842-real-time-cyber-safeguards-on-claude-opus-and-sonnet`.
O corpo vem comprimido (gzip): o SHA-256 dos bytes baixados é o *comprimido* das tabelas, e o do
resultado da descompressão é o *descomprimido*.

captura de 23 de setembro de 2026, 17:50:48 (o Wayback informa esse instante no cabeçalho
`memento-datetime`), e o texto do artigo exibido coincide, linha a linha, com o dos bytes originais.
